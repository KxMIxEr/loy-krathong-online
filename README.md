# เว็บลอยกระทงออนไลน์ (Online Loy Krathong)

เว็บแอปพลิเคชันลอยกระทงออนไลน์ พัฒนาด้วย **Vite + React** รันด้วย **Node.js** และ Deploy ขึ้น **GitHub Pages**

## วิธีการรันบนเครื่อง (Local Setup)
```bash
npm install
npm run dev
```

## วิธีการ Deploy ขึ้น GitHub Pages
```bash
npm run deploy
```
